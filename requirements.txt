# FitGenie - Installation Requirements
# =====================================
# This is a Node.js/Next.js project, not Python.
# Dependencies are managed via package.json
#
# Prerequisites:
# - Node.js v18.17 or later (https://nodejs.org/)
# - npm (comes with Node.js) or yarn/pnpm
#
# Installation Steps:
# 1. Install Node.js from https://nodejs.org/
# 2. Run: npm install
# 3. Create .env.local file with: GROQ_API_KEY=your_api_key_here
# 4. Run: npm run dev
# 5. Open http://localhost:3000
#
# Main Dependencies (from package.json):
# - next: 16.0.7 (React framework)
# - react: 19.2.0 (UI library)
# - react-dom: 19.2.0 (React DOM rendering)
# - groq-sdk: 0.37.0 (Groq AI API client)
# - tailwindcss: 4.x (CSS framework)
# - lucide-react: 0.556.0 (Icon library)
# - @radix-ui/react-navigation-menu: 1.2.14 (UI components)
# - class-variance-authority: 0.7.1 (CSS utilities)
# - clsx: 2.1.1 (Class name utility)
# - tailwind-merge: 3.4.0 (Tailwind CSS utility)
#
# For full dependency list, see package.json
